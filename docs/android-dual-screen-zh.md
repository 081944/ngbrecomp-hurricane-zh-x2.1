# Android 双屏使用说明

本功能用于 Android ARM64 双屏设备，在 AYN Thor 上完成实机测试。其他设备需要将副屏提供给 Android 的 Presentation 接口；单屏设备继续使用原来的游戏界面和输入方式。

## 安装与开启

1. 从本 fork 的 [Releases](https://github.com/081944/ngbrecomp-hurricane-zh-x2.1/releases) 下载 `NinjaGaidenBlack-android-arm64.apk`。
2. 直接覆盖安装旧版，包名和签名不变，保留游戏文件、存档及设置。最低 Android 10，处理器需要支持 `arm64-v8a`，图形驱动需要满足游戏的 Vulkan 要求。
3. 使用自己的 vb-zh-x2.1 游戏数据进入游戏，在“玩法”设置中开启“快速菜单”。检测到兼容副屏后，下屏显示装备面板。
4. “快速菜单暂停”沿用现有逻辑：触按装备按钮时可暂停，松开后执行选择并恢复。仅打开“更多装备”或地图不会主动暂停游戏。

本次 0.9.57 APK 关闭 `debuggable` 和 shell 性能采样入口，继续使用原签名，允许覆盖安装。签名证书名称中的 debug 字样是旧证书的名称，不表示 APK 开启调试权限。

## 常用装备

主武器占左侧，投掷武器在右上，道具在右下。点击武器切换，点击恢复道具使用一次。

分类区域位置和大小固定，内部按钮按当前拥有的物品种类数量排列。没有物品或道具用完时，该分类保留名称和空白内容，其他分类不会挤占它的位置。已装备物品使用更粗的金色边框和标记，其他物品保留清晰边框；名称、数量和等级以放大的文字显示。

## 更多装备

右下角“更多装备”展开忍法、腕轮和服装页面。点击一项后执行切换并自动收起，也可以点击“收起”返回。

服装沿用游戏和现有解锁选项的可用状态，不会因面板本身自动解锁。“剧情默认”用于恢复当前剧情的默认服装。实时换装通过游戏原生加载流程执行，并同步骨骼姿态及角色位置。

## 地图

“地图”和“更多装备”两个按钮等宽，合起来铺满右侧分类下面的区域，两个装备页面的位置和大小一致。

- 点击“地图”后，下屏显示当前区域的原生地图；再次点击同一位置的“关闭”返回装备页面。
- 不要求获得地图道具，不向背包添加物品，也不修改存档中的地图持有状态。
- 当前区域没有地图时，按钮置灰且无法点击；进入有地图的区域后自动恢复。
- 地图显示时，后面的装备按钮不会接收点击。点击“更多装备”可以转到装备扩展页。
- 地图随当前区域更新；坐标有效时显示角色位置标记。

## 功能范围

| 分类 | 面板支持种类 |
| --- | ---: |
| 主武器 | 14 |
| 投掷／远程武器 | 9（包含不同弓箭配置） |
| 立即恢复道具 | 6 |
| 忍法 | 4 |
| 腕轮／结 | 14 |
| 服装 | 8，另有“剧情默认” |

实际显示取决于当前拥有和解锁状态。任务物品、钥匙和自动触发的复活物品不属于此面板。游戏过场、菜单或资源切换等不允许装备操作的时段，会暂时限制对应操作；实体手柄和原游戏菜单继续使用原逻辑。

开发说明和自动检查入口见 [双屏实现文档](android-second-screen.md)。
